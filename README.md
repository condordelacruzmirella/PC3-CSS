# PC3-CSS
# Portafolio Interactivo

## Descripción
Proyecto web con Bootstrap 5, transformaciones CSS y animaciones con `@keyframes`.

## Contenido
- **Bootstrap 5:** Navbar con logo, grid responsivo y formulario de contacto.
- **Transformaciones 2D:** Efectos `:hover` con `rotate`, `scale` y `translate`.
- **Transformación 3D:** Uso de `perspective: 1000px`, `preserve-3d` y `rotateX`/`rotateY`.
- **Animaciones:** Loader de carga (spinner) y animación personalizada de color y tamaño continuo.
